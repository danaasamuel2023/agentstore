DataBundle hero photos — drop your real photos here
=====================================================

The storefront hero and testimonials section reference these files. If a
file is missing, a polished branded placeholder shows instead — so the
page never looks broken while you collect the real shots.

When you drop a real photo in, it appears automatically — no code change.

Recommended files (any aspect ratio is fine; the component object-covers
to fit the slot):

  cash.jpg      — Hero top-left card. A stack of cedis, a MoMo payout
                  notification, hands counting cash — anything that says
                  "money moved". Roughly 4:5 portrait works best.

  reseller.jpg  — Hero bottom-right card. A smiling Ghanaian customer or
                  reseller holding a phone. Authentic > posed. 4:5 portrait.

  avatar-1.jpg  — Testimonial card (Akosua, Kumasi). Face shot, square.
  avatar-2.jpg  — Testimonial card (Kojo, Accra). Face shot, square.
  avatar-3.jpg  — Testimonial card (Ama, Takoradi). Face shot, square.

File sizes — keep each under ~300KB if possible. The page sets explicit
sizes so larger files just waste bandwidth.

Suggested sources:
  - Ask your top resellers if you can use their photo with credit.
  - Buy 5-10 photos from a Ghana-focused stock site (e.g. Nappy, TONL,
    Disrupt Africa Media, or a local Accra photographer).
  - Run a brief photoshoot — phone in hand, MoMo receipt visible, big
    smile. Authentic > airbrushed.
